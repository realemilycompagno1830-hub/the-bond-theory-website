# THE BOND THEORY — Website

This is a complete static, mobile-responsive landing page. It uses the original supplied Evelyn portrait, actual guide-cover image, and official logo.

## Files
- `index.html` — all page content and Selar purchase links
- `styles.css` — responsive design
- `script.js` — mobile navigation
- `assets/` — original supplied images

## Publish with GitHub + Vercel (iPhone or computer)

### 1. Create the GitHub repository
1. Open https://github.com and sign in.
2. Tap **+** → **New repository**.
3. Name it `the-bond-theory-website`.
4. Set it to **Public** (or Private if preferred), then create it.

### 2. Upload the website files
1. Open the new repository.
2. Choose **Add file** → **Upload files**.
3. Upload `index.html`, `styles.css`, `script.js`, and the entire `assets` folder with its three image files.
4. If uploading from a phone, unzip this project first in the Files app, then select the files. Keep the `assets` folder structure intact.
5. Commit the upload to the `main` branch.

### 3. Deploy with Vercel
1. Open https://vercel.com and sign in using GitHub.
2. Tap **Add New** → **Project**.
3. Import `the-bond-theory-website`.
4. Framework preset: **Other**.
5. Build command: leave blank.
6. Output directory: leave blank (or `.` if Vercel requires a value).
7. Click **Deploy**.

Vercel will provide a public URL ending in `.vercel.app`. Open it on your phone and check the portrait, cover and logo.

### 4. Updating the site later
Edit the relevant file in GitHub and commit the change. Vercel automatically redeploys when the connected GitHub repository receives a new commit.
